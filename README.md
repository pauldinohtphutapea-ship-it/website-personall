MATERI 1
1. Modul 1: Computers, Devices, and the Web
Inti materi: Komputer adalah perangkat elektronik yang bekerja berdasarkan instruksi yang tersimpan di memorinya. Jenis komputer: laptop, tablet, desktop, all-in-one, dan server. Data = kumpulan fakta yang belum diproses, seperti teks, angka, gambar, audio, dan video. Informasi = data yang sudah diproses sehingga memiliki makna bagi pengguna. Komputer memiliki input, output, memory, dan storage. Internet adalah jaringan komputer global, sedangkan Web merupakan kumpulan halaman/dokumen yang diakses melalui Internet. Browser digunakan untuk mengakses web, sedangkan search engine digunakan untuk mencari informasi. Membahas digital security, privacy, malware, sistem operasi, aplikasi, serta jaringan kabel dan nirkabel. Kunci ingat: Data → diproses komputer → Informasi

2. Modul 2: Internet, Websites, and Media
Inti materi: Internet adalah kumpulan jaringan di seluruh dunia yang menghubungkan berbagai organisasi dan individu. Internet berawal dari ARPANET pada September 1969. Koneksi Internet dapat menggunakan kabel maupun nirkabel. WWW/Web terdiri dari kumpulan halaman web. Website = kumpulan halaman web yang saling berkaitan. Web server = komputer yang mengirimkan halaman web kepada pengguna. Browser = aplikasi untuk mengakses dan melihat halaman web. Homepage = halaman pertama suatu website. Search engine = perangkat lunak untuk menemukan informasi di web. Membahas website, media digital, email, chat, VoIP, FTP, dan netiquette. Kunci ingat: Internet ≠ Web Internet adalah infrastrukturnya, Web adalah salah satu layanan yang berjalan di atasnya.

3. Modul 3: Computers and Mobile Devices
Inti materi: Membahas berbagai perangkat: laptop, tablet, desktop, smartphone, kamera digital, e-book reader, wearable device, dan game device. Mobile computer adalah komputer pribadi yang mudah dibawa. Server menyediakan layanan untuk komputer/perangkat lain dalam jaringan. Virtualisasi memungkinkan sumber daya komputer digunakan untuk membuat server virtual. Terminal memiliki kemampuan pemrosesan terbatas dan berkomunikasi dengan server. Contoh terminal: ATM dan kios swalayan. Supercomputer adalah komputer dengan kemampuan pemrosesan sangat tinggi. Cloud computing menyediakan sumber daya dan layanan melalui Internet. Membahas game device, embedded computer, port, konektor, Bluetooth, Wi-Fi, NFC, keamanan hardware, dan ergonomi. Kunci ingat: Server → menyediakan layanan Cloud → sumber daya melalui Internet

4. Modul 4: Programs and Apps
Inti materi: Program/software = kumpulan instruksi yang memberitahu komputer apa yang harus dilakukan. Aplikasi = program yang membantu pengguna melakukan tugas tertentu. Sistem operasi (OS) mengoordinasikan aktivitas hardware dan software. Jenis software: retail, custom, web app, mobile app, shareware, freeware, open source, dan public domain. Productivity applications membantu pekerjaan sekolah, kantor, dan aktivitas sehari-hari. Contoh: word processor, presentation, spreadsheet, database, accounting, project management. Graphics & media applications: CAD, image editing, photo editing, video/audio editing. Communication applications: email, chat, browsing, video conference, file transfer. Security tools: firewall, antivirus, spyware remover. Kunci ingat: Hardware = perangkat fisik Software = instruksi/program OS = penghubung dan pengelola hardware/software

5. Modul 5: Digital Security, Ethics, and Privacy
Inti materi: Digital security berkaitan dengan perlindungan hardware, software, data, dan informasi. Cybercrime = tindakan ilegal yang dilakukan secara online/berbasis Internet. Membahas berbagai risiko seperti: hacker pencurian informasi pencurian software serangan Internet kerusakan sistem White hat hacker menguji keamanan sistem secara etis dan tidak bertujuan merugikan. Black hat hacker menerobos sistem untuk melakukan tindakan merugikan, seperti pencurian atau kerusakan. Membahas software piracy, etika penggunaan teknologi, dan privacy. Kunci ingat: Security → melindungi sistem Ethics → menggunakan teknologi secara bertanggung jawab Privacy → melindungi informasi pribadi

MATERI 2

6. Modul 6: Komponen Komputer
Inti materi: Komponen utama komputer yang dibahas antara lain: Motherboard → papan sirkuit utama tempat berbagai komponen terhubung. Processor/CPU → menafsirkan dan menjalankan instruksi. Control Unit → mengatur dan mengoordinasikan operasi komputer. ALU → melakukan operasi aritmatika dan logika. Register → menyimpan data/instruksi sementara. System clock → mengatur waktu operasi processor. Memory → menyimpan instruksi, data yang sedang diproses, dan hasil pemrosesan. Membahas juga representasi data. Kunci ingat: CPU → memproses RAM/Memory → menyimpan sementara Motherboard → menghubungkan komponen

7. Modul 8: Media Penyimpanan
Inti materi: Media penyimpanan adalah tempat fisik untuk menyimpan data, informasi, program, dan aplikasi. Storage device digunakan untuk membaca dan/atau menulis data. Reading = memindahkan data dari storage ke memory. Writing = memindahkan data dari memory ke storage. Data pada storage tetap ada meskipun komputer dimatikan. Capacity menunjukkan jumlah data yang dapat disimpan. HDD menggunakan piringan magnetik untuk menyimpan data. Membahas track, sector, platter, read/write head, RPM, serta berbagai media penyimpanan lainnya. Juga membahas cloud storage dan enterprise storage. Kunci ingat: Memory → penyimpanan sementara Storage → penyimpanan jangka panjang

8. Modul 9: Sistem Operasi
Inti materi: Sistem operasi (OS) adalah software yang mengoordinasikan sumber daya hardware komputer. OS menjadi antarmuka antara pengguna, aplikasi, dan hardware. Fungsi utama OS: menjalankan komputer (booting) mengelola program mengelola memory mengatur perangkat mengelola file menyediakan koneksi jaringan memantau kinerja membantu keamanan sistem Cold boot = menyalakan komputer dari kondisi mati. Warm boot = melakukan restart. Kernel adalah inti OS yang mengelola memory, perangkat, aplikasi, dan sumber daya komputer. Antarmuka dapat berupa command-line maupun grafis. Kunci ingat: OS = pengelola utama komputer

9. Modul 10: Mengkomunikasikan Konten Digital
Inti materi: Komunikasi digital adalah proses pertukaran data, instruksi, dan informasi antarperangkat. Sistem komunikasi terdiri dari: Sending device Communication device Communication channel/media Receiving device Network = kumpulan komputer/perangkat yang saling terhubung. Manfaat jaringan: komunikasi berbagi hardware berbagi data/informasi berbagi software transfer dana Jenis jaringan: LAN → wilayah terbatas MAN → wilayah metropolitan WAN → wilayah geografis luas PAN → jaringan personal Membahas protokol, perangkat komunikasi, jaringan rumah, serta media transmisi kabel dan nirkabel. Kunci ingat: LAN → kecil MAN → kota/metropolitan WAN → luas

10. Modul 11: Basis Data, Data, dan Informasi
Inti materi: Database/basis data = kumpulan data yang disusun agar mudah diakses, dicari, dan digunakan. Data dapat berupa teks, angka, gambar, audio, dan video. Informasi = data yang sudah diproses sehingga bermakna dan berguna. DBMS digunakan untuk membuat, mengelola, menambah, mengubah, menghapus, mencari, serta membuat laporan dari data. Hierarki data: Bit → Byte → Character → Field → Record → File → Database Field → satu jenis data tertentu. Record → kumpulan field yang berhubungan. Primary key → field yang mengidentifikasi record secara unik. File → kumpulan record terkait. Pengelolaan database: Menambah record Mengubah record Menghapus record Melakukan validasi data. File processing vs Database File processing dapat menyebabkan redundansi data dan data terisolasi. Database approach memungkinkan banyak pengguna/program berbagi data dalam satu basis data. Kunci ingat: Database → tempat mengelola data DBMS → software untuk mengelola database
